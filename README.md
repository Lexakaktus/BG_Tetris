# Tetris (CLI, C, ncurses)
## Описание проекта
Этот проект — реализация классической игры Тетрис на языке C с терминальным интерфейсом (CLI) с использованием библиотеки ncurses.
Архитектура разделена на две независимые части:
- Игровая логика (библиотека) — отвечает за состояние игры, фигуры, столкновения, очки и уровни.
- Пользовательский интерфейс (CLI) — отвечает за отображение игрового поля и обработку ввода пользователя.

Логика игры построена на основе конечного автомата (Finite State Machine), что делает поведение игры формализованным и легко расширяемым.
Проект реализован в структурном стиле на стандарте C11 и сопровождается unit-тестами.

## Возможности игры

Реализованы все основные механики классического Тетриса:
- Вращение фигур
- Перемещение влево и вправо
- Ускоренное падение фигуры (hard drop)
- Автоматическое падение по таймеру
- Уничтожение заполненных линий
- Отображение следующей фигуры (preview)
- Завершение игры при достижении верхней границы поля
- Подсчет очков
- Сохранение рекорда между запусками
- Система уровней с увеличением скорости

## Логика игры (Finite State Machine)
- Start — ожидание начала игры
- Spawn — генерация новой фигуры
- Move — обработка пользовательского ввода
- Shift — автоматическое смещение фигуры вниз
- Attach — фиксация фигуры и проверка линий
- Game Over — завершение игры (при проигрыше)
- Terminate - выключение игры ( при выходе из игры, либо спустя время после проигрыша)

## Сборка и запуск
Сборка проекта и запуск (в первый раз):

```make```

Запуск игры:

```make play```  либо ```./build/game```

Запуск юнит-тестов:

```make test``` 

Удаление: 

```make uninstall```

Также реализованы все стандартные цели для gnu программ (dvi, dist, install...)

## 🕹 Управление

| Клавиша        | Действие |
|---------------|----------|
| ← / a            | Переместить фигуру влево |
| → / d            | Переместить фигуру вправо |
| ↓ / s           | Ускоренное падение |
| Space / Enter | Вращение фигуры |
| P             | Пауза |
| Q / ESC             | Выход из игры |
| S             | Начать игру |


## Используемые технологии

- Язык: C (C11)
- Компилятор: gcc
- Интерфейс: ncurses
- Тестирование: check (+gcov, для проверки покрытия)
- Сборка: Makefile
- Архитектура: Finite State Machine (FSM)
